# Subtract Lab — исходный код и локальный запуск

В репозитории — доработанная версия исходного кода v1.1.0 с чёрно-белым вычитанием и автоматическим 3D-ресэмплингом B в сетку A. Это не неизменённый исходный релиз.

## Запуск у себя

1. Распакуй архив и открой терминал в папке `subtract-lab-v1.1.0`.
2. Запусти локальный HTTP-сервер (нужен Python 3):

```bash
python -m http.server 8000 --bind 127.0.0.1 --directory dist
```

В Linux/macOS команда Python часто называется `python3`, а в Windows можно использовать `py` вместо `python`.

3. Открой в браузере: http://127.0.0.1:8000/?lang=ru
4. Для остановки сервера нажми Ctrl+C в терминале.

Открывать `dist/index.html` двойным щелчком не нужно: ES-модули и Web Workers требуют HTTP. Сервер слушает только локальный адрес 127.0.0.1.

Интерфейс по умолчанию английский. Русская версия — `?lang=ru`; языки переключаются в верхней строке. Переключение перезагружает страницу и очищает загруженные данные: сначала экспортируй результат. При загруженных пользовательских сериях или изменённом совмещении появится предупреждение.

Для запуска приложения не нужны Node.js, npm или установка пакетов: декодеры и WebAssembly уже включены в `dist/vendor/`. После распаковки приложение может работать без доступа к интернету при запуске через локальный сервер. DICOM читаются и обрабатываются в браузере.

## Где что находится

- `dist/index.html`, `dist/style.css` — интерфейс.
- `dist/app.mjs`, `dist/localization.mjs` — управление приложением, языки, отображение и экспорт.
- `dist/dicom.mjs`, `dist/io-worker.js` — чтение DICOM.
- `dist/core.mjs`, `dist/register-worker.mjs` — геометрия и жёсткая корегистрация.
- `dist/resampling.mjs`, `dist/resample-worker.mjs` — 3D-ресэмплинг в сетку референса и сглаживание при укрупнении вокселя.
- `dist/vendor/` — библиотеки, декодеры и их лицензии.
- `tests/` — автоматические проверки вычислений, форматов и граничных случаев.
- `scripts/fixtures.mjs` — генератор синтетических DICOM для тестирования.
- `README.md` — подробности алгоритмов, форматов и ограничений (на английском).

## Разработка и тесты

Нужен современный Node.js с File/Blob.bytes() и vm.constants.USE_MAIN_CONTEXT_DEFAULT_LOADER (проверено на Node.js 24).

```bash
npm ci
npm test
```

Рабочие JS/CSS-файлы находятся непосредственно в `dist/`: отдельного шага сборки нет. После правок обнови страницу браузера.

## Версия

Основа — снимок v1.1.0 на 24.10.2026 (исходный Git commit: f6361af5b1a6d1c4e740bd950529d95de655f654). Поверх него добавлены исправления ориентации исходной серии, корегистрации небольших объёмов, маски float padding, ограничений распаковки ZIP/Deflated DICOM и размеров NIfTI. Нынешний репозиторий не следует считать указанным исходным Git-коммитом.

Вариант интерфейса viewer-first: загрузка A и B кнопками или перетаскиванием находится прямо в соответствующих окнах изображения; постоянная левая панель убрана, параметры совмещения и вычитания размещены ниже рабочей области. Работает и на узких экранах. Приложение по-прежнему запускается локально из `dist/`.

В третьем окне вместо «Шахмат» есть «Форточка»: A отображается фоном, совмещённая B — внутри подвижного прямоугольника без рамки. Указатель мыши ведёт форточку по срезу, на сенсорном экране её можно перетаскивать; размер меняется ползунком. Экспорт NIfTI остаётся численным вычитанием, а PNG сохраняет текущий вид.

Для ручного уточнения совмещения включи «Двигать B» над третьим окном: протяжка сдвигает B поверх A, кнопки поворачивают на 1° в плоскости просмотра. При отпускании выполняется полный 3D-пересчёт; проверяй результат во всех трёх плоскостях.

Демо отмечено рядом с названием синтетической серии, без отдельной плашки. Кнопка со стрелкой у выбора плоскости сбрасывает масштаб изображения до 1×, а не открывает полноэкранный режим.
